Adding the Downex browser extension (macOS)
===========================================

Downex takes over downloads from Firefox, Edge, Chrome, Brave and Chromium through its
browser extension. Browsers do not let programs install extensions themselves, so it has to
be added once in each browser.

First register Downex with the browsers (the native-messaging host "com.downex.host"),
once per user, in Terminal, after Downex.app is in its final place (again after moving it):

    /Applications/Downex.app/Contents/Helpers/downex-nmhost register

Firefox and Edge install the extension from their add-on sites once Downex is listed there.
Chrome, Brave and Chromium (and Firefox and Edge until then) load it from inside the Downex
app, next to this file:

    /Applications/Downex.app/Contents/Resources/extension/chrome-mv3     (Chrome, Edge, Brave, Chromium)
    /Applications/Downex.app/Contents/Resources/extension/firefox-mv3    (Firefox)

(Use the app's real location if it is not in /Applications.) The browsers' file dialogs
show Downex.app as one item: to choose a folder inside it, press Command-Shift-G in the
dialog, paste the path above and press Return.

Do not move or delete Downex.app while the extension is loaded from it.


Firefox
-------

1. Open https://addons.mozilla.org, search for "Downex" and click "Add to Firefox".
2. Firefox lists what the add-on may do and the data it hands to the Downex program on this
   Mac; click "Add" to install it. Firefox keeps it and updates it from then on.

Until Downex is listed there, Firefox can load it from the app for one session only
(release versions of Firefox keep only add-ons that Mozilla has signed):

1. Open about:debugging#/runtime/this-firefox
2. Click "Load Temporary Add-on...", press Command-Shift-G, paste

       /Applications/Downex.app/Contents/Resources/extension/firefox-mv3/manifest.json

   press Return and click "Open".

Firefox removes temporary add-ons when it quits; repeat these steps after a restart, or
install the listed add-on as soon as it is there.


Edge
----

Once Downex is listed there, open https://microsoftedge.microsoft.com/addons, search for
"Downex" and click "Get". Edge keeps it and updates it from then on. If its button then
says that Downex does not accept this copy, this version of Downex does not know the listed
copy yet: remove it, and load Downex from the app as below until Downex has
updated.

Until Downex is listed there, load it from the app as described for Chrome below, on
edge://extensions.


Chrome, Brave and Chromium (and Edge until Downex is listed)
------------------------------------------------------------

1. Open the extensions page:
   Chrome:   chrome://extensions
   Edge:     edge://extensions
   Brave:    brave://extensions
2. Turn on "Developer mode".
3. Click "Load unpacked", press Command-Shift-G, paste

       /Applications/Downex.app/Contents/Resources/extension/chrome-mv3

   press Return and click "Select".
4. The extension "Downex" appears with the ID

       @EXTENSION_ID@

   Downex accepts a copy loaded from this folder only with this ID. If a different ID is
   shown, the folder was not the one from this app.

Keep "Developer mode" on. Chrome 134 and later turn off extensions loaded this way when it is
switched off, and downloads then stay in the browser. The browser may warn about
developer-mode extensions when it starts; that is expected for extensions loaded this way.


Checking that it works
----------------------

Click the Downex button in the browser's toolbar (it may be hidden behind the extensions
(puzzle) icon). It shows whether Downex is reachable. When it is not, open Downex from
Applications once, check that "downex-nmhost register" above reported no error, then try
again.


After updating Downex
---------------------

Downex installs its updates itself when you choose Update now.

- Installed from addons.mozilla.org or Edge Add-ons: the browser updates the extension
  itself; nothing to do.
- Loaded from the app (Chrome, Brave, Chromium, or Edge before the listing): click the
  reload arrow of the Downex card on the extensions page (or restart the browser).
- Loaded as a temporary add-on in Firefox: load it again.

Run "downex-nmhost register" again only when the app moved.


Uninstalling
------------

1. Remove the extension in the browser (extensions page, "Remove").
2. In Terminal:

       /Applications/Downex.app/Contents/Helpers/downex settings --launch-at-login off
       /Applications/Downex.app/Contents/Helpers/downex daemon stop
       /Applications/Downex.app/Contents/Helpers/downex-nmhost unregister

3. Move Downex.app to the Trash.

Your download list and settings stay in ~/Library/Application Support/Downex and the logs
in ~/Library/Logs/Downex; delete those folders as well to remove everything. Downloaded
files are never deleted.
