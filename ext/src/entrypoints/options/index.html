Capture rules

Saved when you press Save

Choose which downloads the browser hands to Downex. Downloads from private windows and blob:/data: downloads always stay in the browser, and holding Alt while clicking a link keeps that download in the browser.

Separated by spaces, commas or new lines, e.g. zip iso tar.gz.

0 captures any size. Downloads of unknown size are always captured.

One per line. *.example.com also matches example.com. Downloads started on pages of these hosts stay in the browser too; the toolbar menu’s “Send downloads to Downex” switch adds or removes the page’s host here.

Failed downloads

Saved as you change it

When a download fails or stops in the browser, the toolbar menu offers to finish it with Downex from the bytes already saved. Downex first checks that the server still has the same file.

Videos on web pages

Saved as you change it

A Download button over a video lists what the browser loaded for it (MP4 files and streams) and, with yt-dlp (downloaded with Deno on first use), the site's MP4 qualities. The one you choose is saved as one MP4 file. Protected (DRM) videos and live streams are never offered. Whether a site's terms allow downloading is your responsibility.

One per line. *.example.com also matches example.com. The site of the tab decides, so its embedded players follow it; a panel's "Don't show on" and the toolbar menu's switch add or remove the page's host here. Saved when you leave the field.
